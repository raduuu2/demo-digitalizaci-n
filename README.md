# YouTube: de 2005 a hoy

Web del Proyecto de Digitalización (Primera Evaluación) sobre la evolución de YouTube.
Autor: Roberto Daniel Radu Bucan · 2º DAM · 2026.

Basada en la plantilla de la asignatura (HTML5 + Bootstrap 5.3.9 por CDN), con la paleta adaptada a YouTube.

## Estructura

```text
├── index.html          Inicio: identidad, historia y servicio actual
├── evolucion.html      Los 6 hitos tecnológicos, infografía y esquema antes/después (Content ID)
├── organizacion.html   Estructura del grupo, áreas, directivos y presencia en el mundo
├── canales.html        Canales con más suscriptores: mundo, habla hispana y España
├── css/style.css
└── img/                Imágenes y recursos generados con NotebookLM en la Fase 2
```

## Cómo abrirla

Abre `index.html` en el navegador (con conexión a Internet para cargar Bootstrap y los vídeos de YouTube).

Los vídeos de YouTube solo se reproducen si la web se abre desde un servidor, por ejemplo GitHub Pages. Con doble clic en `index.html`, YouTube muestra el «Error 153».
